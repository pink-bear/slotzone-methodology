## The Core EV Formula

```
EV = (Bonus × RTP) ÷ Wagering − Bonus
```

Example: a $100 bonus with 35x wagering at 96% RTP returns an Expected Value of −$97.26 — meaning the average player loses $97 before being able to withdraw.
